DeutschPath v2 — Free Offline Practice Edition

Open index.html in a browser, or deploy this entire folder using https://app.netlify.com/drop.

New: grammar drills, listening exercises using browser voice, mistake review, daily streak, daily goal, guided offline conversation, and progress backup/import.

All titles/navigation are in English. Grammar explanations are in Roman Urdu with an optional English switch.

Important: This is a starter curriculum (30 lessons), NOT a complete A1–B2 course. The conversation practice is scripted, NOT an AI model. Cloud login/sync is NOT enabled; use Export/Import in Settings to move progress between devices.

Hosting can be free within provider limits. No external libraries, API keys or paid subscriptions required for this version.
