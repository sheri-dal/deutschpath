# DeutschPath Academy v3

Static German learning website, free to host on GitHub Pages.

## Content
- 48 original starter learning units, 8 per level: A1.1, A1.2, A2.1, A2.2, B1, B2.
- 384 German vocabulary items with Roman Urdu meanings.
- Each unit includes a grammar explanation in Roman Urdu, an example, vocabulary, reading, browser text-to-speech listening, a writing/speaking task, and a multiple-choice quiz.
- Progress, daily streak, mistake review, local writing notes and JSON backup.

**Limitations:** This is an expanded starter academy, NOT a comprehensive CEFR-certified A1–B2 curriculum. Listening uses browser-generated speech, not recorded dialogues. Speaking is self-guided; writing is not automatically graded. No login, cloud sync or AI chat is included.

## Deploy on GitHub Pages
Upload `index.html` and `curriculum.js` into the root of the existing `deutschpath` repository (replace the old index.html). Settings > Pages > Deploy from branch > main > /(root). Wait for the deployment to finish and hard refresh.

## Offline
Files can be opened together locally, but browser data persistence may vary for file:// pages. Host over HTTPS for reliable storage.
